---
description: Discuss new features and product requirements without writing code.
---

1. **Frame the goal**: Define *what* to build and *why*; focus on user value, feasibility, and high-level requirements. Push back on scope that doesn't serve the current goal.

2. **Understand**: Ask clarifying questions to understand the vision. Identify edge cases or potential conflicts with existing features.

3. **Plan**: Outline a roadmap or feature specification. Break the feature into manageable tasks. Discuss technical feasibility briefly.

4. **Output**: A summary of the feature requirements and a proposal for `task.md` or `implementation_plan.md` to track it. Do not write code yet; agree on the plan first.
