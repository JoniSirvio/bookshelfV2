description: Discuss UX/UI improvements and design choices without writing code.
---

1. **Ground in design context**: Base all feedback on `.cursor/rules/design.mdc` (brand, color, principles). Focus on usability, aesthetics, visual consistency, and accessibility.

2. **Analyze**: Review any provided screenshots or descriptions. If no specific topic is provided, ask what UI/UX aspect to discuss.

3. **Discuss & Plan**: Provide design feedback or suggestions. Describe proposed changes rather than writing code immediately. If a plan is agreed upon, outline the high-level tasks needed.

4. **Output**: Clear, concise design recommendations. If helpful, generate or update `implementation_plan.md` focusing on UI tasks; do not write code unless explicitly asked to prototype.
